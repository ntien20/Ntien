> Một trang web bách khoa thiên văn học và trải nghiệm vũ trụ huyền ảo, u ám và rợn ngợp chuẩn điện ảnh Sci-Fi, chạy ở tần số quét cực mượt **120 FPS**.

## ✨ Tính Năng Nổi Bật

- 🚀 **Động cơ 120 FPS Siêu Mượt**: Tối ưu hóa GPU compositing, khử độ trễ V-Sync với `desynchronized: true`, đồng bộ delta-time 8.33ms.
- 🪐 **Mô Phỏng Thái Dương Hệ & Vành Đai Tiểu Hành Tinh (Kepler Orrery)**: Trực quan hóa 8 hành tinh, Sao Diêm Vương, hơn 650 mảnh vỡ tiểu hành tinh, Apophis 2029 và khách liên sao 'Oumuamua.
- 💥 **Bộ Đánh Giá Thảm Họa Va Chạm (Asteroid Impact Simulator)**: Tính toán động năng (Megatons TNT), kích thước hố va chạm, độ Richter và quy mô sóng thần / mùa đông va chạm.
- 🕳️ **Phòng Thí Nghiệm Hố Đen Gargantua**: Chân trời sự kiện, đĩa bồi tụ tương đối tính Doppler beaming, hiệu ứng kéo sợi mì Spaghettification và giãn nở thời gian (Time Dilation HUD).
- 🔊 **Âm Thanh Vũ Trụ Thời Gian Thực (Web Audio Synth)**: Tái tạo sóng hạ âm trầm 43.2Hz, gió không gian và nhịp đập tín hiệu Sao Xung (Pulsar).
- 🧬 **Máy Tính Bụi Sao (Stardust Origin Calculator)**: Giải mã cội nguồn các nguyên tử Hydro, Oxy, Carbon, Sắt trong cơ thể bạn từ Vụ Nổ Lớn và Siêu Tân Tinh.
- 📚 **Bách Khoa Toàn Thư Thiên Thể**: Hơn 20 hồ sơ khoa học chi tiết kèm cổng tri thức tương tác (Modal).

## 🚀 Hướng Dẫn Chạy Trang Web

### Cách 1: Chạy cục bộ với Python
```bash
python -m http.server 8080
```
Sau đó truy cập `http://localhost:8080` trên trình duyệt.

### Cách 2: Triển khai công khai với GitHub Pages
1. Đẩy mã nguồn lên GitHub Repository.
2. Vào **Settings** -> **Pages**.
3. Tại mục **Branch**, chọn `main` và thư mục `/(root)` -> Nhấn **Save**.
4. Trang web sẽ trực tiếp hoạt động công khai tại: `https://<username>.github.io/<tên-repo>/`.
